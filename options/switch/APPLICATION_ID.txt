Switch build — Application ID checklist
======================================

When your client provides the Nintendo Developer Portal Application ID:

1. Open options/switch/application.nmeta
2. Replace BOTH placeholder values with the real ID (same hex string in each):
   - <ApplicationId>
   - <SaveDataOwnerId>
3. Format: 0x0100XXXXXXXXXXXX (16 hex digits after 0x)

Assets in this folder (ready for build):
- application.nmeta  (metadata — IDs pending)
- icon.bmp             (256x256, 24-bit BMP — verified)
- banner.jpg           (eShop marketing — optional for first devkit install)

GameMaker: confirm Switch SDK path under Platform Settings before exporting.
